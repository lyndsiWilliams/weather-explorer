# Weather Explorer

Weather Explorer is a frontend-only weather dashboard built with React, TypeScript, and Vite. Its current scaffold is in place, with live weather and climate views planned.

## Running locally

Requires Node.js 24.15 or newer. The project uses pnpm through Corepack:

```sh
corepack pnpm install
corepack pnpm dev
```

## Checks

```sh
corepack pnpm test
corepack pnpm run test:coverage
corepack pnpm run lint
corepack pnpm run format:check
corepack pnpm run typecheck
corepack pnpm run build
```
